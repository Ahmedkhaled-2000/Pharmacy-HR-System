# الدليل الهندسي الشامل لتشغيل وربط خادم الواتساب (WhatsApp Gateway Architecture)

يوثق هذا الدليل المعمارية الهندسية المتطورة لخادم الواتساب المدمج لمنظومة إدارة الموارد البشرية والرواتب، وكيفية ربطه وتشغيله بسلاسة على تطبيق الويندوز وعلى أي متصفح هاتف أو كمبيوتر دون أي تعقيدات.

---

## 1. المعمارية الهندسية (Dual-Engine System)

تم بناء النظام ليعمل بنموذج هجين (Hybrid Architecture) فائق المرونة:

```
┌────────────────────────────────────────────────────────┐
│             تطبيق الويندوز المكتبي (Electron)           │
│   ┌────────────────────────────────────────────────┐   │
│   │ محرك Node المدمج (utilityProcess / execPath)   │   │
│   │ خادم الواتساب المحلي (Baileys Engine)          │   │
│   │ المنفذ الداخلي والخارجي: 3100                 │   │
│   │ مجلد الجلسة: %APPDATA%\PharmacyHR_Data         │   │
│   └────────────────────────────────────────────────┘   │
└───────────────────────────┬────────────────────────────┘
                            │
              (شبكة الصيدلية المحلية LAN / Wi-Fi)
                            │
       ┌────────────────────┴────────────────────┐
       ▼                                         ▼
┌──────────────────────────┐       ┌──────────────────────────┐
│   متصفحات أجهزة الصيدلية │       │ هواتف المشرفين والإدارة  │
│  (ربط تلقائي بالـ IP)    │       │ (WhatsApp Web Fallback)  │
└──────────────────────────┘       └──────────────────────────┘
```

---

## 2. الجزء الأول: تطبيق الويندوز (تشغيل تلقائي مدمج 100%)

### كيف يعمل بدون تثبيت Node.js خارجي؟
1. **المحرك المدمج في Electron**:
   - يستخدم التطبيق تقنية `utilityProcess` المدمجة في Electron، أو تشغيل الملف التنفيذي للبرنامج مع تعيين متغير البيئة `ELECTRON_RUN_AS_NODE=1`.
   - هذا يعني أن **أي جهاز ويندوز خام** لا يحتوي على Node.js سيقوم بتشغيل خادم الواتساب بكل كفاءة وسرعة فور إطلاق البرنامج.

2. **حزم ملفات السيرفر والاعتماديات في المثبت (`Setup.exe`)**:
   - تم ضبط ملف التحزيم `electron-builder.json5` لنقل مجلد `server/**/*` داخل `asarUnpack`.
   - تم تضمين حزم `express` و `cors` و `qrcode` و `@whiskeysockets/baileys` ضمن حزم الإنتاج (`dependencies`).

3. **حفظ بيانات الجلسة بأمان دائم**:
   - يتم حفظ جلسات الاقتران ومفاتيح التشفير (`whatsapp-auth`) داخل:
     `%APPDATA%\PharmacyHR_Data\whatsapp-auth`
   - هذا المسار يمتلك فيه المستخدم كامل الصلاحيات دون الحاجة لـ `Run as Administrator`، وتبقى الجلسة محفوظة حتى بعد إغلاق أو تحديث البرنامج.

4. **المراقبة الذاتية (Watchdog Timer)**:
   - يقوم التطبيق بفحص صحة المنفذ `3100` كل 30 ثانية، وفي حال حدوث أي توقف مفاجئ للخدمة، يعيد إطلاقها ذاتياً في الخلفية.

## 3. الجزء الثاني: بيئة المتصفح وربط كل جهاز بواتساب مستقل

### أ. كيفية ربط المتصفح بسيرفر الويندوز عبر الشبكة المحلية (LAN):
1. **الخطوة الأولى (جهاز السيرفر الرئيسي بالصيدلية)**:
   - افتح تطبيق الويندوز المكتبي (سيبدأ السيرفر تلقائياً).
   - قم بتشغيل ملف `scripts/allow_firewall_3100.bat` كمسؤول (Run as Administrator) **مرة واحدة فقط** للسماح للأجهزة الأخرى بالاتصال عبر المنفذ `3100`.

2. **الخطوة الثانية (على المتصفح في الهاتف أو الجهاز الثاني)**:
   - افتح رابط المنظومة على المتصفح.
   - ادخل إلى قسم **"💬 مركز مراسلات الواتساب"**.
   - اضغط على زر **"🔍 استكشاف تلقائي للشبكة"**؛ سيقوم المتصفح بفحص الشبكة والربط مع سيرفر الويندوز فوراً.
   - أو اضغط على **"🌐 ربط الأجهزة والموبايلات"**، واكتب عنوان الـ IP (مثال: `http://192.168.1.15:3100`) ثم اضغط **"📌 حفظ لهذا الجهاز فقط"**.

---

### ب. خيار "كل جهاز بربط واتساب مستقل":
- إذا كانت الصيدلية تحتوي على أكثر من جهاز أو فرع، ويرغب كل مسؤول في ربط هاتفه الخاص لإرسال الرسائل:
  - يمكن لكل جهاز تشغيل نسخته الخاصة أو توجيه المتصفح لمنفذ/جهاز مختلف.
  - زر **"📌 حفظ لهذا الجهاز فقط"** يقوم بحفظ الرابط في الـ `localStorage` للمتصفح الحالي، مما يتيح استقلالية كاملة لكل جهاز دون تغيير إعدادات باقي الأجهزة.

---

### ج. البديل الفوري الذكي (WhatsApp Web Direct Fallback):
- إذا كنت خارج الصيدلية (تتصفح المنظومة عبر باقة الموبايل أو من المنزل)، ولا يمكنك الوصول للشبكة المحلية:
  - اضغط على زر **"📲 إرسال مباشر عبر WhatsApp Web"** المتاح بجانب زر الإرسال.
  - سيقوم النظام بـ:
    1. فتح محادثة الموظف الرسمية على WhatsApp Web فوراً وتجهيز نص الرسالة المنسق مع بيانات الراتب.
    2. توليد وتنزيل كشف المرتب كملف PDF رسمي جاهز للإرفاق والإرسال بنقرة واحدة.
  - وبذلك **لا يتعطل عملك مطلقاً** حتى في حال عدم توفر السيرفر المحلي.
